# BOM 说明

`bom.csv` 是 V0 的硬件清单与核验状态记录，UTF-8、逗号分隔、首行为表头。

## 列含义

| 列 | 含义 |
| --- | --- |
| BOM版本 | 该行最后一次修订所处的 BOM 版本，属行级修订标记，因此同一文件内不同行取值不同。此语义由取值分布推断（2026-09-19），仓库内未另有定义 |
| 物料编号 | 稳定 ID，供需求、决策与任务记录引用 |
| 子系统 | 动力、飞行控制、感知、机械等分组 |
| 状态 | 已锁定 / 当前基线 / 候选 / 待定 等，与 PROJECT_CONTEXT 的状态词对应 |
| 优先级 | P0–P3 |
| 型号或规格、数量、单件质量_g、总质量_g、外形尺寸_mm、电气或通信接口 | 记录值；写“待定”表示尚无证据 |
| 证据状态 | 该行结论的依据（用户确认、厂商手册、实机实测、清单核对） |
| 待确认事项 | 尚未闭合的验证项 |

## 维护规则

- 实测能力变化时同步更新本表、`docs/REQUIREMENTS.md` 与相关决策；目录或文档整理不得把硬件结果改为 PASS。
- 不删除历史行，用证据状态与待确认事项记录当前结论和失效条件。
- 同一设备的接口基线与在用实物可分两行记录，但标定与实测证据必须指向同一行，避免出现互相矛盾的状态。

## 双目相机两行的关系（2026-09-19 核对）

- `CAM-STEREO-USB-001`：双目深度输入的接口基线（USB 免驱、硬件同帧、左右拼接），待确认项为型号、传感器、快门类型与安装方向等。
- `CAM-STEREO-DEV-001`：当前接入验证平台的实物相机，2026-09-16 完成模式枚举与 20 mm 棋盘标定。
- 两行指同一设备族；标定、帧率与深度证据以 `CAM-STEREO-DEV-001` 为准。

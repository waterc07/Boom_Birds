# BOM 说明

`bom.csv` 是 V0 的硬件清单与核验状态记录，UTF-8、逗号分隔、首行为表头。

## 当前适用范围

`CMP-DEV-001`、`CMP-FINAL-001` 中 K230/AX630C 的候选描述属于旧选型记录，不再作为当前采购或比较任务。当前平台路线以 `CMP-PI5-001` 和[项目入口](../../README.md#工程基线)为准：Pi 5 验证、后续 RK3576，最终板卡待验证。保留 CSV 原始行及 ID 便于追溯，不因本次文档清理改写测量或采购证据。

## 列含义

| 列 | 含义 |
| --- | --- |
| BOM版本 | 该行最后一次修订所处的 BOM 版本，属行级修订标记，因此同一文件内不同行取值不同。此语义由取值分布推断（2026-09-19），仓库内未另有定义 |
| 物料编号 | 稳定 ID，供需求、决策与任务记录引用 |
| 子系统 | 动力、飞行控制、感知、机械等分组 |
| 状态 | 已锁定 / 当前基线 / 候选 / 待定 等，与 [项目入口](../../README.md#工程基线)的状态词对应 |
| 优先级 | P0–P3 |
| 型号或规格、数量、单件质量_g、总质量_g、外形尺寸_mm、电气或通信接口 | 记录值；写“待定”表示尚无证据 |
| 证据状态 | 该行结论的依据（用户确认、厂商手册、实机实测、清单核对） |
| 待确认事项 | 尚未闭合的验证项 |

## 维护规则

- 实测能力变化时同步更新本表、`docs/REQUIREMENTS.md` 与相关决策；目录或文档整理不得把硬件结果改为 PASS。
- 不删除历史行，用证据状态与待确认事项记录当前结论和失效条件。
- 同一设备的接口基线与在用实物可分两行记录，但标定与实测证据必须指向同一行，避免出现互相矛盾的状态。

## 双目相机两行的关系（2026-09-19 核对）

- `CAM-STEREO-USB-001`：双目深度输入的接口基线（USB 免驱、硬件同帧、左右拼接），待确认项为型号、传感器、快门类型与安装方向等。
- `CAM-STEREO-DEV-001`：当前接入验证平台的实物相机，2026-09-16 完成模式枚举与 20 mm 棋盘标定。
- 两行指同一设备族；标定、帧率与深度证据以 `CAM-STEREO-DEV-001` 为准。

## 厂商资料基线

以下承接原工程上下文中的资料摘录，本次未重新联网核验；规格不等于当前实物验收。

### MicoAir743v2-AIO-45A

厂商手册确认：STM32H743VIH6、BMI088 + BMI270 双 IMU、SPL06 气压计、microSD、7 路 UART、8 路电机输出、1 路 I²C、3–6S VBAT、5 V/2 A 与 12 V/2 A BEC、4×45 A AM32 电调，支持 DShot600、双向 DShot 和 PX4。板体 36×36×8 mm、10 g，安装孔距 25.5×25.5 mm，要求 45° 安装。

资料来源：<https://micoair.cn/zh/docs/flight-controller/micoair743-aio-series/micoair743v2-aio-45a-manual>

### MTF-02P

厂商手册确认：光流测距一体设计，5 V 供电、平均 100 mA、LVTTL 3.3 V 串口、115200 baud、50 Hz；尺寸 21.6×16×6.5 mm、重量 1.5 g；MTF-02P ToF 在 90% 反射率条件下标称 0.02–6 m，提供 `Mavlink_px4` 和默认 `AUTO` 协议模式。实际安装方向、串口占用、协议模式、EKF2 参数和真实场景性能仍需实板验证。

资料来源：<https://micoair.cn/zh/docs/sensors/sensors/mtf-02-02p-sensors>

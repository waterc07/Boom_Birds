# AI 工作与交接

更新：2026-09-15。行为规则以根 AGENTS 为准，本文件不增加审批门槛。

## 每项任务

确认 cwd、目标、限制 → 读 CURRENT_STATUS → 按需定位代码或证据 → 完成修改 → 适量验证 → 更新状态与交付。若受阻，继续完成独立部分，明确缺少的信息或条件。

## 交接模板

```text
目标与完成条件：
工作目录 / 设备：
已完成文件：
版本：Git 提交；无 Git 时使用哈希或备份清单
验证：命令、环境、结果、证据路径
未验证：相关精度、性能或硬件限制
下一步：具体入口与交付物
限制：用户禁止事项、所缺设备或信息
```

需要跨任务交接时按日期和主题写入 docs/tasks/；简单问答不创建额外记录。不要复制凭据或完整聊天历史。

## GPT-6 优化依据

依据 2026-09-15 核对的 [GPT-6 Astra 官方指南](https://developers.openai.com/api/docs/guides/latest-model)：明确常规选择可自主执行、冲突需解释、回复简明、测试与变更规模相称；子代理使用按项目需求限定。本次仅优化提示词组织，未更改模型、推理预算或服务参数，未进行模型效果对比实验。

## 文档职责

AGENTS 管行为；CURRENT_STATUS 管事实；PROJECT_CONTEXT 管架构；NEXT_TASK 管候选任务；PROJECT_LAYOUT 管路径；模块 README 管运行；DECISIONS 管历史。规则原件、日志和历史快照不作为 AI 指令，不批量改写。
